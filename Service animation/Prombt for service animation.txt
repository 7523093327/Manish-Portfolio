Section concept:
This is an interactive “Services Switchboard”.
The left side contains 6 clickable 8-bit display modules.
The right side contains one large active service screen.
When a service becomes active, the corresponding left display lights up, and the right screen changes content.

Main behavior:
The left service modules auto-cycle one by one.
The active service changes automatically every few seconds.
Users can also click any left module to make it active.

Important visual behavior from the GIF:
1. Left modules are normally inactive.
2. Inactive modules have a dark 8-bit screen with low brightness.
3. The active module does NOT highlight the full outer module body.
4. Only the inner 8-bit display/screen lights up.
5. The active screen gets a blue glow.
6. The active text becomes brighter.
7. The glow should feel like a retro LED/pixel display turning on.
8. The glow should fade smoothly, not switch instantly.

Left module transition:
When a new module becomes active:
- previous active screen fades back to dark
- previous screen glow fades out
- new screen glow fades in
- new service text becomes brighter
- the active screen gets a subtle inner blue illumination
- the outer metal/body frame remains mostly unchanged

Use these state classes:
.service-module
.service-module.is-active
.service-module__screen
.service-module__screen-glow
.service-module__label

Inactive state:
- screen background: very dark green/black
- label opacity: around 0.45 to 0.6
- glow opacity: 0
- no strong blue border

Active state:
- screen glow opacity: 1
- label opacity: 1
- label color: bright blue or pale electric blue
- screen border/glow becomes blue
- optional slight text-shadow/glow

Right screen behavior:
The right screen is a single large panel.
It should update based on the active service.

When active service changes:
- old content fades out
- screen briefly dims or transitions
- new content fades in
- service title appears
- short description appears
- service illustration appears
- “What you get” bullets appear

The right panel should feel like a display screen changing state, not a full page reload.

Right screen transition:
Use a soft transition:
- opacity: 0 → 1
- y: 12px → 0
- scale: 0.98 → 1
- duration: 350–500ms
- easing: ease-out

Screen reflection:
Important detail from the GIF:
The right screen has a slow diagonal reflection/highlight moving across it.
This should be a subtle glossy light streak moving diagonally from top-left to bottom-right or bottom-left to top-right.
It should be very slow and continuous.
It should sit above the screen background but below the content.
It should not distract from text/illustration.

Implement reflection as:
- a pseudo-element on the right screen
- linear-gradient with transparent edges and soft white/blue center
- position absolute
- transform rotate(-18deg) or similar
- animate background/translate slowly
- duration around 6–10s
- opacity around 0.18–0.28

Example:
.screen-reflection {
  position: absolute;
  inset: -40%;
  background: linear-gradient(
    120deg,
    transparent 35%,
    rgba(255,255,255,0.28) 48%,
    rgba(255,255,255,0.10) 55%,
    transparent 68%
  );
  transform: translateX(-45%) rotate(-12deg);
  animation: screenReflection 8s linear infinite;
  pointer-events: none;
}

@keyframes screenReflection {
  from { transform: translateX(-45%) rotate(-12deg); }
  to { transform: translateX(45%) rotate(-12deg); }
}
